# Ze Harness Homebrew tap

Install the native Ze Harness CLI on supported macOS and Linux machines:

```sh
brew install zephyrcloudio/ze/ze-harness
```

Upgrade with `brew upgrade ze-harness` and uninstall with `brew uninstall ze-harness`.
This tap installs versioned binaries from [downloads.ze.dev](https://downloads.ze.dev).
The formula pins each archive's SHA-256 checksum. Linux requires glibc 2.28+,
kernel 4.18+, and `libatomic`. Intel macOS and Alpine Linux are not supported.

For other installation methods, see [Ze Harness](https://ze.dev).
